# Tiara2 v2.1.2 changes

## Single experimental change

The genus cap can now be applied independently within each data split.

```yaml
genus_balance:
  enabled: true
  scope: per_split
  max_species_per_genus: 1
```

- `scope: global` reproduces v2.1: one species per genus across the complete corpus.
- `scope: per_split` implements v2.1.2: one species per genus independently in `train`, `validation`, and `test`.
- The planner fails fast in `per_split` mode if any accession has no resolvable split.
- The JSON report records `scope`, `grouping`, and per-split/per-class counts.

## Commands

```bash
# Preview only
tiara2 genus-balance --dry-run

# Write selection, decisions, and report files
tiara2 genus-balance

# Reproduce the v2.1 global strategy without editing code
tiara2 genus-balance --set genus_balance.scope=global
```

The low-level script also exposes the same switch:

```bash
python3 scripts/plan_genus_balance.py ... --scope per_split
```
