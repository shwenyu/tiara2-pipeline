# Tiara2 v2.3.0 hierarchical code

This patch keeps the exact v2.1.3 sampling and introduces a shared encoder with root/euk/prok/organelle heads. `2.3.1` and `2.3.2` are reserved profiles in `schema.py`; v2.3.0 does not consume virus.

## Metadata contract
TSV columns: `record_id`, `split`, `species_taxid`, optional `host_species_taxid`, `euk_group`, `virus_cluster_id`. Every euk record must resolve to one of the eight configured euk groups. Ambiguous `Archaeplastida` is intentionally rejected unless the TSV distinguishes land plant from algae.

## Commands
Create the metadata file first (the initial patch omitted this required step):
```bash
python -m tiara.hierarchical init-metadata \
  --train-ready /ssd/shouhanyu/Tiara2/corpus_ready_v2_1_3_bpbalanced \
  --out /data/shouhanyu/Tiara2_v2_3_0/metadata/hierarchical_labels.tsv

# Exit code 2 here means unresolved euk labels remain. Curate those rows first.
python -m tiara.hierarchical audit \
  --metadata-tsv /data/shouhanyu/Tiara2_v2_3_0/metadata/hierarchical_labels.tsv
python -m tiara.hierarchical prepare --version 2.3.0 \
  --train-ready /ssd/shouhanyu/Tiara2/corpus_ready_v2_1_3_bpbalanced \
  --metadata-tsv hierarchical_labels.tsv \
  --tfidf tiara/models/tfidf-models-v2.2.0/k7-first-stage \
  --out /ssd/shouhanyu/Tiara2_v2_3_0/cache/hierarchy_k7
# train
torchrun --standalone --nproc_per_node=8 \
  -m tiara.hierarchical.train \
  --features /ssd/shouhanyu/Tiara2_v2_3_0/cache/hierarchy_k7 \
  --out /data/shouhanyu/Tiara2_v2_3_0/models/v2.3.0 \
  --epochs 50 \
  --batch 1024 \
  --workers 8 \
  --prefetch 4 \
  --amp \
  --log-every 25

# publish
python publish_hierarchical_model.py \
  --source /data/shouhanyu/Tiara2_v2_3_0/models/v2.3.0 \
  --repo-root /home/shouhanyu/tiara2_pipeline \
  --tag v2.3.0 \
  --tfidf tiara/models/tfidf-models-v2.2.0/k7-first-stage \
  --k 7 \
  --set-current
# infer
python -m tiara.hierarchical classify \
  --checkpoint \
  /data/shouhanyu/Tiara2_v2_3_0/models/v2.3.0/hierarchical_model.pt \
  --tfidf \
  /home/shouhanyu/tiara2_pipeline/tiara/models/tfidf-models-v2.2.0/k7-first-stage \
  --input input.fasta \
  --output predictions_v2.3.0.tsv \
  --batch 512 \
  --device cuda:0 \
  --min-len 1000

# 或采用publish以后的软连接
python -m tiara.hierarchical classify \
  --checkpoint \
  /home/shouhanyu/tiara2_pipeline/tiara/models/hierarchical-models-current/hierarchical_model.pt \
  --tfidf \
  /home/shouhanyu/tiara2_pipeline/tiara/models/tfidf-models-v2.2.0/k7-first-stage \
  -i input.fasta \
  -o predictions.tsv
```

Do not use `unknown_euk=other_protist` for the canonical run until the taxonomy audit is complete. The default is hard failure.
