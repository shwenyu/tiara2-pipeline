# Tiara2 v2.3.1 — Euk completeness 增量实现

## 唯一主变量

v2.3.1 只补齐八个 Euk leaf 的标签和数据：

`fungi / land_plant / algae / metazoa_vertebrate / metazoa_invertebrate / alveolata / stramenopiles / other_protist`

以下内容全部冻结：v2.3.0 fragment IDs 与 split、k7 TF–IDF、base feature memmap、`2048→1024` encoder、dropout 0.2、AdamW、lr 0.001、50 epochs、batch 1024、root `WeightedRandomSampler`、`root_macro_f1` checkpoint selection。

Virus 不属于 v2.3.1；代码将 Virus root profile 延后到 v2.4.0。

## 修改/新增文件

### 修改

- `schema.py`：修正 v2.3.1 profile，不再误启用 Virus。
- `train.py`：读取 base+delta composite shards；保持 v2.3.0 训练契约；记录全部 head 指标。
- `evaluate.py`：Root/Euk/Prok/Organelle per-class 指标、confusion matrix、cascade accuracy。
- `__main__.py`：接入 v2.3.1 全命令链。
- `test_schema.py`：按当前路线图测试 profile。

### 新增

- `completeness.py`：accession→taxid→lineage→leaf 审计与修标签。
- `freeze.py`：冻结 FASTA、ordered record IDs、metadata、TF–IDF SHA-256。
- `delta.py`：已有 fragment pool 中提取 Euk delta；ID/sequence 去重及 split leakage 防护。
- `features_v231.py`：复用 base X，仅重建 base Euk labels；仅计算 delta X。
- `gates.py`：覆盖、leakage、leaf recall、benchmark、checkpoint gate。
- `release.py`：gate 后原子发布、备份、current symlink、SHA256SUMS。
- `config/config_v2_3_1_euk_completeness.yaml`。
- `scripts/run_v2_3_1_euk_completeness.sh`。

## 输入契约

Base/candidate metadata 采用 TSV。字段名支持常见别名，但 canonical 输入建议包含：

```text
record_id  accession  split  legacy_class  species_taxid
split_group_id  duplicate_cluster_id  euk_group  lineage
```

候选 FASTA 必须已经使用原 v2c chop、QC、dedup 规则处理。本版本不会改变 chop 规则。目录可为：

```text
candidate_root/train/eukarya.fasta
candidate_root/validation/eukarya.fasta
```

也支持按 leaf 分文件，如 `train/alveolata.fasta`。

## 执行顺序

### 1. 冻结 v2.3.0 base

```bash
python -m tiara.hierarchical freeze-base \
  --train-ready /ssd/shouhanyu/Tiara2/corpus_ready_v2_1_3_bpbalanced \
  --tfidf tiara/models/tfidf-models-v2.2.0/k7-first-stage \
  --metadata-tsv /data/shouhanyu/Tiara2_v2_3_0/metadata/hierarchical_labels.tsv \
  --out /data/shouhanyu/Tiara2_v2_3_1/manifests/base_freeze_manifest.json
```

生成完整 file SHA-256 与 ordered-record-ID SHA-256；canonical delta/prepare 使用 `--verify-base full`。

### 2. 审计并修 metadata

```bash
python -m tiara.hierarchical audit-euk \
  --base-metadata /data/shouhanyu/Tiara2_v2_3_0/metadata/hierarchical_labels.tsv \
  --source-index /data/shouhanyu/Tiara2/index/all_entities.tsv \
  --pool-metadata /path/to/existing_fragment_pool.tsv \
  --taxdump-dir /data/shouhanyu/Tiara2/taxonomy/taxdump \
  --overrides-tsv /path/to/euk_group_overrides.tsv \
  --out /data/shouhanyu/Tiara2_v2_3_1/audit
```

输出：

- `hierarchical_labels_v2_3_1.tsv`：修正版副本，不覆盖 v2.3.0。
- `euk_record_audit.tsv`：逐条 resolution/action。
- `euk_coverage.tsv`：每个 leaf 的 base/pool/source 覆盖。
- `euk_completeness_report.json`。

根因按证据标记为：`label_error_recovered`、`bp_balance_not_selected`、`source_fragments_missing`、`source_missing`。

### 3. 构建 Euk delta

```bash
python -m tiara.hierarchical build-euk-delta \
  --base-train-ready /ssd/shouhanyu/Tiara2/corpus_ready_v2_1_3_bpbalanced \
  --base-metadata .../audit/hierarchical_labels_v2_3_1.tsv \
  --candidate-root /path/to/candidate_fragments \
  --candidate-metadata /path/to/candidate_fragments.tsv \
  --audit-report .../audit/euk_completeness_report.json \
  --base-freeze-manifest .../base_freeze_manifest.json \
  --verify-base full --out .../euk_delta
```

只消费 audit 缺失的 `(split, leaf)`。拒绝：base 重复 ID、base/delta 重复 sequence、metadata split 不一致、species/split-group/dedup-cluster 跨 split、缺 taxid或未解析 leaf。

### 4. 生成 composite features

```bash
python -m tiara.hierarchical prepare-v231 \
  --base-features /ssd/shouhanyu/Tiara2_v2_3_0/cache/hierarchy_k7 \
  --base-train-ready /ssd/shouhanyu/Tiara2/corpus_ready_v2_1_3_bpbalanced \
  --curated-base-metadata .../hierarchical_labels_v2_3_1.tsv \
  --delta-root .../euk_delta --delta-metadata .../euk_delta_metadata.tsv \
  --tfidf tiara/models/tfidf-models-v2.2.0/k7-first-stage \
  --base-freeze-manifest .../base_freeze_manifest.json \
  --verify-base full --out /ssd/shouhanyu/Tiara2_v2_3_1/cache/hierarchy_k7_composite
```

不会复制/重算 base X；只生成 base `euk.i64` override 与 delta shard。

### 5. 训练

```bash
python -m tiara.hierarchical train \
  --features /ssd/shouhanyu/Tiara2_v2_3_1/cache/hierarchy_k7_composite \
  --out /data/shouhanyu/Tiara2_v2_3_1/models/v2.3.1 \
  --epochs 50 --batch 1024 --lr 0.001 --hidden 2048,1024 --dropout 0.2
```

参数漂移会直接失败；Euk branch balancing 留给 v2.3.2，early stopping 留给 v2.3.3。

### 6. 评估、gate、publish

```bash
python -m tiara.hierarchical evaluate-v231 \
  --truth truth.tsv --predictions predictions.tsv --out evaluation.json

python -m tiara.hierarchical gate-v231 \
  --completeness-report .../euk_completeness_report.json \
  --composite-features .../composite_features.json \
  --evaluation evaluation.json \
  --base-metadata .../hierarchical_labels_v2_3_1.tsv \
  --delta-metadata .../euk_delta_metadata.tsv \
  --baseline-benchmark v2.3.0_canonical.json \
  --current-benchmark v2.3.1_canonical.json \
  --checkpoint .../hierarchical_model.pt \
  --max-legacy-regression-pp 0.20 --min-leaf-recall 0.05 \
  --out acceptance_gates.json
```

所有 gate 通过后才允许 `publish-v231`。发布会重新生成本版本 `model_manifest.json`，原子替换目标目录并刷新 `current` symlink，从而避免旧 checkpoint/stage manifest 残留。

## 分阶段执行器

```bash
export SOURCE_INDEX=/data/shouhanyu/Tiara2/index/all_entities.tsv
export POOL_METADATA=/path/to/existing_fragment_pool.tsv
export TAXDUMP_DIR=/data/shouhanyu/Tiara2/taxonomy/taxdump
export CANDIDATE_ROOT=/path/to/candidate_fragments
export CANDIDATE_METADATA=/path/to/candidate_fragments.tsv

bash scripts/run_v2_3_1_euk_completeness.sh freeze
bash scripts/run_v2_3_1_euk_completeness.sh audit
bash scripts/run_v2_3_1_euk_completeness.sh delta
bash scripts/run_v2_3_1_euk_completeness.sh prepare
bash scripts/run_v2_3_1_euk_completeness.sh train
```

脚本对未设置的必需变量立即失败，不使用猜测路径。
